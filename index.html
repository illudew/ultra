MENTAL MODELS · REFERENCE

底层原理库

不把技巧当作魔法口诀。这里整理的是可以反复迁移的思维框架：每种框架都说明何时适用、怎样操作，以及它的边界。

数值感知

数量级与上下界

先把问题压缩到合理的数量级，再求精确值。用极端情况检查结果是否可能，避免小数点、单位和常识错误。

下界 ≤ 合理答案 ≤ 上界

适用：物理估算、选择题筛选、复杂计算的结果校验。

计算策略

分解、补偿、重组

把难算的数改写成邻近的易算数，再修正差值。例如 49×21 = 50×21 − 21。

(a ± δ)b = ab ± δb

适用：心算、近似计算、检查代数变形。

视觉建模

把关系变成图像

先明确横轴、纵轴、原点、单位和变量，再判断图形。直线斜率表示变化率，截距表示初始值或基准值。

y = kx + b → 斜率 k，截距 b

边界：图像能揭示关系，但图像本身不能替代条件与证明。

逻辑推理

条件、结论与反例

分清“若 P 则 Q”和“若 Q 则 P”。若 P→Q 且 Q 为假，则 P 必为假；但 Q 为真不能反推 P 为真。

P → Q，¬Q ⇒ ¬P

适用：数学证明、实验结论、阅读论证和排除错误选项。

模型意识

变量与因果关系

将复杂情境写成“输入—机制—输出”。区分相关、因果和共同原因；每次只改变一个关键变量时，才容易判断其作用。

输出 = f(输入，条件，参数)

适用：物理建模、实验设计、数据解释。

语言精度

定义、条件、例子

解释一个概念时，先给必要特征，再说明边界条件，最后用正例和反例检验。避免用同义词循环解释概念。

概念 = 核心特征 + 适用边界

适用：写作、口头表达、理解教材和构建知识体系。

物理直觉

量纲与极限检查

公式两边必须具有相同量纲。把参数推到零、无穷大或对称情形，检查模型是否给出合理结果。

[左侧] = [右侧]

适用：推导检错、判断选项、发现隐藏假设。

应试策略

选择题排除与有依据的猜测

先判断单位、符号、数量级与极端情况，再检查选项是否满足题设。所谓“蒙题”只能作为最后一步：优先排除与题干矛盾的选项，不把选项分布、字数或“感觉”当作证据。

约束检查 → 排除 → 验算

适用：时间受限的选择题。它不能替代理解，也不能保证猜中。
