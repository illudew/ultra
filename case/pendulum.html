教学案例 01 · 标准库 Python · 合成数据

用单摆练习一条完整的证据链。

从周期数据、模型选择和拟合，到残差、不确定度与结果边界。目标是复现一份透明的分析，而不是用合成数据声称测得真实重力加速度。

数据性质：21行记录由明确公式与固定偏移构造，没有进行真实实验。小数位用于重现输入，不代表测量仪器精度。

01 / 把“测量 g”改写成可检查的问题

在小摆角、轻绳、近似质点、阻尼很弱的理想模型下，单摆周期与有效摆长的关系为 T = 2π√(L/g)。这里的 L 是支点到摆球质心的距离，T 是一次完整往返的周期。我们问：一组带固定计时扰动的合成数据，能否复现 T² 与 L 的近似线性关系？斜率如何对应输入中的 g？

这不是对真实重力场、摆球或实验室仪器的检验。它把科研工作拆成一个可以独立核对的练习：问题 → 输入 → 假设 → 分析 → 输出 → 局限。

02 / 保留原始输入与构造规则

数据有7种长度，0.30至0.90 m、每0.10 m一组；每组3次计时，每次20个完整周期。参考参数 gref = 9.80665 m/s²。所有计时按下式生成并保留6位小数：

t20 = 20 × 2π√(L / gref) + δt

δt 为预先写定的偏移，不是抽样随机噪声。例如0.30 m的三次偏移是 −0.12、+0.04、+0.11 s；其余各组的完整偏移在数据说明中列出。不要把这种预设的扰动序列当作现实误差分布。

03 / 从周期到自由截距拟合

  1. 逐行计算 T = elapsed_s / cycles，核对单位和周期定义。
  2. 同一长度的3次周期先取平均，再平方：y = T̄²。它与先平方再平均并不完全相同，复现时必须说明选择。
  3. 对7个 (L, y) 点拟合 y = aL + b。保留截距，不强制过原点；这使偏移在诊断中可见，但截距本身不能唯一解释误差来源。
  4. 由 a = 4π²/g 得到 g = 4π²/a，逐点计算残差 rᵢ = yᵢ − (aLᵢ + b)。
  5. 等权OLS以残差平方和估计 s² = Σrᵢ²/(n−2)，斜率标准误为 u(a) = √[s²/Σ(Lᵢ−L̄)²]。一阶传播给 u(g) = g·u(a)/a。

此处使用等权普通最小二乘（OLS），把 L 当作已知。由于平方变换有 u(T²) ≈ 2T u(T)，纵轴误差通常是异方差，等权处理只是教学近似。不要将脚本的标准误解释为已经完成了实验误差预算。

04 / 运行、记录与独立核对

将脚本与数据保存到同一文件夹；需要 Python 3，无第三方依赖。在仓库根运行：

python3 case/pendulum/generate.py
python3 case/pendulum/fit.py --verify

生成器默认只核对CSV是否与文档公式逐字节一致，不修改输入；只有显式增加 --write 才会重建数据。分析脚本按自身位置读取 data.csv，因此从其他工作目录运行也有效。它输出JSON，列出每个长度的 T̄² 和残差，以及以下汇总。允许浮点末位差异：

05 / 结果可以说明什么

这组输入按小角单摆公式构造，因此拟合回接近 gref 是预期结果。它验证了“文件—运算—报告”的教学闭环，不能证明真实摆运动满足该模型，也不构成一次独立物理发现。

若按两位有效数字表示条件标准不确定度，可以写 g = 9.809 ± 0.011 m/s²，并紧接着说明“仅为合成数据、当前等权OLS模型下的标准不确定度”。不能省略这一限定，更不能把它称为95%置信范围。

真实实验还要讨论摆长定义与校准、摆角、阻尼、支点、计时反应偏差、周期误计、空气与温度等适用因素。重复测量能揭示部分随机变化，却不能自动消除系统偏差；残差很小也不证明模型完整。

如果测量 T 的不确定度已知，可比较对 T² 使用合理权重的拟合；若 L 也有显著不确定度，应选择同时处理横纵轴误差的方法。方法选择须依据测量过程，不能只挑让拟合结果更接近参考值的算法。

06 / 自己完成三个小任务

  1. 独立算一组：用0.30 m三条记录计算 T̄ 和 T̄²，与JSON对应点核对；记录先平均还是先平方。
  2. 查看残差：画 r-L 图或整理残差表，描述符号、尺度与可能趋势；不能仅报告一项“拟合优度”。
  3. 改变一个假设：比较自由截距与强制过原点的结果，或为所有总时间加相同偏移，说明为什么参数会变化。过原点拟合可在脚本副本中用 a₀ = Σ(Lᵢyᵢ)/ΣLᵢ²、b₀ = 0，再算 g₀ = 4π²/a₀；本练习不要求沿用自由截距时的标准误公式。保留原数据副本与改变记录。

完成标准：另一位读者可取得相同输入、按命令得到一致主结果，并能从你的报告识别数据为合成、模型假设、等权近似及未纳入的不确定度。

用研究日志记录步骤，用报告核查表审查结论；先读不确定性与结果报告可帮助区分不同的“误差”。
