# 单摆合成数据案例

这里的21行记录是**教学合成数据，不是实验测量或现实科研结果**。

## 输入构造

参考值 `g_ref = 9.80665 m/s²`，长度 `L = 0.30, 0.40, …, 0.90 m`。
每个长度合成3次20完整周期计时：

`elapsed_s = round(20 × 2π × sqrt(L / g_ref) + offset_s, 6)`

| L / m | 三次 offset / s |
|---|---|
| 0.30 | −0.12, +0.04, +0.11 |
| 0.40 | +0.08, −0.06, +0.03 |
| 0.50 | −0.04, +0.09, −0.07 |
| 0.60 | +0.05, −0.10, +0.08 |
| 0.70 | −0.08, +0.03, +0.10 |
| 0.80 | +0.10, −0.05, +0.02 |
| 0.90 | −0.02, +0.07, −0.09 |

不使用随机数，输入可精确重建。`length_m` 是支点到质心的模型长度；`cycles` 是完整周期数，不是单向摆动数；`elapsed_s` 的六位小数用于精确重建教学输入，不代表真实秒表分辨率。

## 执行

Python 3，无第三方依赖，从仓库根运行：

```sh
python3 case/pendulum/generate.py
python3 case/pendulum/fit.py --verify
```

生成器默认按字节核对输入，不写文件。若确实需要重建，运行 `python3 case/pendulum/generate.py --write`，它会覆盖案例CSV；请先保留你修改过的输入。

也可从其他工作目录运行脚本的绝对路径，输入始终相对于脚本查找。

## 方法与应得到的结果

每个长度先计算三次周期 `T = elapsed_s / cycles` 的平均值，再令 `y = mean(T)²`。不是先平方再平均。用7个 `(L, y)` 点做自由截距、等权OLS：`y = aL + b`。

- 斜率约 `4.024599895 s²/m`
- 截距约 `0.001828923 s²`
- `g = 4π²/a ≈ 9.809277602 m/s²`
- 条件OLS标准不确定度约 `0.011414829 m/s²`
- 最大绝对残差约 `0.003395831 s²`

正常的浮点实现差异允许末位不同。`--verify` 检查7组/21行、合理的g范围、残差和标准不确定度范围；这验证教学输入/运算闭环，不验证真实物理模型。

## 适用范围

本案例把长度当作准确输入；忽略长度测量、计时器校准、反应延迟、有限摆角、阻尼和空气浮力等系统项。平方变换后 `u(T²) ≈ 2T u(T)`，误差通常并非同方差；等权OLS是教学近似。脚本的标准不确定度是该拟合假设下的结果，不能直接当作真实实验的完整不确定度。真实数据应建立误差预算，再考虑加权拟合或同时处理横纵轴误差的方法。
