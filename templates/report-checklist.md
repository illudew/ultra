# 结果报告核查表

项目/版本/日期：

- [ ] 问题、数据来源和教学/真实数据性质写清楚。
- [ ] 模型、适用条件、变量定义与单位完整。
- [ ] 数据筛选、剔除与缺失值处理有依据和记录。
- [ ] 原始数据、处理脚本、依赖和执行命令可追溯。
- [ ] 拟合方法与参数选择说明清楚，残差图或残差表可查看。
- [ ] 区分重复性、不确定度、系统偏差和模型偏差。
- [ ] “±”后说明标准不确定度或扩展不确定度；后者注明覆盖因子与依据。
- [ ] 结果有效数字与不确定度相称，坐标和图注含单位。
- [ ] 解释哪些结论成立、哪些证据仍不足，不以拟合好等同模型真实。
- [ ] 引用可回到原始来源，公开材料符合实际许可。
- [ ] 另一位读者能按说明复现主要数字，并知道允许的数值差异。
